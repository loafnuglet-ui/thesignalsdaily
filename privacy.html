Privacy Policy

Last updated: September 30, 2026

This policy covers the website at this address and the Signals Daily Uploader ("the App"), a private tool used by The Signals Daily to publish its own videos to its own YouTube channel.

Use of YouTube API Services

The App uses YouTube API Services to upload videos. By using the App you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the App accesses

  • The App requests only the youtube.upload permission, which lets it upload videos and set their title, description and privacy status on the channel that authorizes it.
  • It does not read, collect or store any viewer data, comments, subscriber lists, watch history, or any other YouTube or Google account data.
  • The only account that authorizes the App is The Signals Daily's own channel.

How data is used and stored

  • The App stores an OAuth access/refresh token only on the channel owner's own computer, solely so it can upload that channel's videos. It is never shared, sold or sent anywhere except Google's servers when uploading.
  • Uploaded videos, titles and descriptions are content created by The Signals Daily.
  • No data is shared with third parties.

This website

This site is a static page hosted on GitHub Pages. It sets no cookies of its own and uses no analytics or trackers. GitHub may log standard request information (such as IP addresses) as described in the GitHub Privacy Statement.

Revoking access

Access granted to the App can be revoked at any time from the Google security settings page. Deleting the locally stored token file also removes the App's access.
